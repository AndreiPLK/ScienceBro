# Article material — ScienceBro / AInstein audit

Purpose: collect data, visuals, and narrative material from the ScienceBro project so
that a journal/blog article can be assembled later. Everything here is raw material,
in English, collected as the work happens. Nothing in this folder makes scientific
claims beyond the proof-gate allowed wording.

## Structure

| Path | Content |
| --- | --- |
| `DATA_LOG.md` | Append-only log: every significant event with measured numbers |
| `data/key-measurements.md` | The headline measured results, single source for article numbers |
| `data/communication-timeline.md` | Timeline of the human-AI collaboration (who decided what) |
| `visuals/` | Dashboard screenshots, quest-map SVG, residual maps |
| `story-ai-as-engine.md` | Narrative A: AI as an engine/tool |
| `story-ai-as-colleague.md` | Narrative B: AI as a colleague |

## Candidate venues (from roadmap §18)

- AI-for-science methodology: Machine Learning: Science and Technology
- Research software: JOSS
- Scientific result (if the audit produces one): CQG / PRD
- Popular/blog: founder's channels

## Rules

- Numbers only from measured artifacts (`projects/ainstein-audit/results/processed/`).
- Words "discovery / confirmation / refutation" are banned until independent validation.
- Both narratives describe the SAME factual timeline; only the framing differs.
