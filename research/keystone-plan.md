# Замковый камень: план по образцу Mansfield 2502.20372 (прочитан, стр. 1-8)

## Архитектура его доказательства («все уровни сразу», Венециано D≤10)
1. Контурное представление коэффициентов B_{n,j} (двойной контур, ур. 2.11).
2. D≤6: положительность = произведение рядов с положительными коэффициентами.
3. D≤10: конечное число отрицательных членов Лорана ГАСИТСЯ добавкой
   P_j(x,y) с нулевым вычетом («умное прибавление нуля», ур. 2.14-2.15).
4. РАВНОМЕРНОСТЬ ПО j: индукция по j через свёрточную рекурсию
   Q^{j+1} = Q^j + Q^j * G (коэффициенты Грегори, ур. 2.20) + лемма о
   положительности G_k (интегральное представление, ур. 2.25).
5. Конечный исключительный набор (малые n, j) — явная машинная проверка.

## Перенос на наш CHR-гравитон (наша задача шире: параметр λ, любое D)
- Роль «индукции по j с положительным ядром» → наш подход №2: рекурсия
  B_{j+1} ← B_j из мастер-формулы (один лишний множитель (D+c+2r) и сдвиг
  E-весов). НАЙТИ ядро и доказать его знак в поясе.
- Роль «умного нуля» → лекарство от нашей слепоты третьего порядка
  t₀(X−1)³ (far-below): добавка с нулевым вычетом вместо факторизации.
- Роль «конечного исключительного набора» → наш конвейер ножей 2-12 + Z3.
- Роль его равномерного хвостового утверждения → наш биномиальный коллапс
  (1−X)^{j−1} (подход №1) — сшить с рекурсией.

## Заморожено до эксперимента (frozen)

  P_{n+1} = K_n · P_n + R_n с K_n > 0 и R_n ≥ 0 в поясе (или конечное число

  монотонно по n (иначе анзац рекурсии переделать).

## Обновление после чтения AEHM 2201.11575 (стр. 15-23) — 2026-08-16

### Два ключевых факта
1. **Даже AEHM не смогли сделать fixed-spin строгим** (конец разд. 4.3.1:
   «we were unable to turn this approximate inequality into a rigorous
   bound» для D=10). Наш замковый камень — признанно трудная задача уровня
   поля; строгую равномерность для Венециано дал только Mansfield-2025
   другим путём (свёртка+индукция). Честный вывод: наши 4 быстрых провала —
   нормальная скорость для этой горы.
2. **ГЛАВНОЕ СТРУКТУРНОЕ НАБЛЮДЕНИЕ: резидю CHR — это КВАДРАТ произведения
   линейных множителей** по t: R(n,t) = [((1+lam)/2+lam*t)_{n-1} / (...)]^2,
   а Похгаммер = произведение линейных факторов. У AEHM ровно такая
   структура у ЗАМКНУТЫХ струн (резидю = квадрат открытого) — и для неё
   у них готова машинерия ТРОЙНОГО контурного представления (ур. 3.23-3.24
   + Appendix C).

### Новый маршрут замкового камня (по образцу AEHM разд. 3 + Mansfield)
Шаг A: переписать резидю CHR как квадрат произведения линейных факторов
  (роты t_k = -((1+lam)/2+k)/lam, все вещественные) — уже почти сделано
  в статье 2.
Шаг B: вывести двух/тройное контурное представление наших B_{n,j}
  (Rodrigues + Laplace, как их разд. 3; квадрат => по контуру на фактор).
Шаг C: манифестная положительность в лёгком диапазоне D (их разд. 4.1) +
  asymptotics fixed spin (их 4.3.1) + строгая равномерность по j индукцией
  со свёрточным ядром (Mansfield 2.20) — теперь с λ как параметром.
Статус: маршрут заморожен как основной. idea_origin: LITERATURE+MIXED.
