Обновлено: 2026-08-17, вечер. Любая сессия (компьютер, веб, телефон)

## Где мы в науке

**Программа:** квантово-гравитационный S-матричный бутстрап (NORTH_STAR.md).
Вопрос: обязаны ли согласованные гравитационные амплитуды быть струнными.

**Доказано и опубликовано (4 работы, DOI):** остров с краями, берег
замкнутой струны, мастер-формула, теорема лезвий (нож 3).

**Доказано машинно, ждёт публикации:** теоремы ножей j = 4..12 — каждая
область каждого ножа имеет проходящий артефакт, детерминированный гейт
(`tests/unit/test_theorem_gate.py`) зелёный. Ножи 13-20 в очереди счёта.

**Главная теорема (все ножи сразу):** НЕ доказана. Локализована:
- есть замкнутая гипергеометрическая форма всех скобок (4320 точных проверок,
  `results/chr_closed_form.json`);
- знакопеременная спектральная сумма — точный квадрат (проблема знака в весах);
- задача сведена к одному взвешенному неравенству;
- измерен «запас прочности»: он положителен всегда, но экспоненциально мал,
  отношение margin(j)/margin(j+2) → ~11 (`results/keystone_asymptotics.json`);
- перевал стоит на t*/j ≈ 0.42 — значит работает метод перевала.

## Что делать дальше (архитектура доказательства, по шагам)

1. Записать знакопеременную сумму как контурный интеграл (Меллин-Барнс).
2. Найти комплексный перевал при t = α j, α ≈ 0.42, извлечь главный член
   с ЯВНОЙ положительной константой.
3. Оценить остаток равномерно по λ в каньоне (λ ≈ 7..19, зависит от j).
4. Малые j — машиной (уже сделано для j ≤ 12).
Это скелет Мансфилда (arXiv:2502.20372) с нашими измеренными константами
для сверки каждого шага.

## Правила, действующие всегда

- Один тяжёлый процесс за раз; метрикам CPU/RAM не верить (в песочнице лгут),
  здоровье процесса — только по росту лога.

- Провалы сохраняются с сигнатурами (их уже 14+ — карта тупиков).
