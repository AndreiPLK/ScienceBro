### Доказано (три леммы)

1. **Бета-редукция.** Знак ножа = знак ОДНОГО интеграла с бета-весом от
   D-СВОБОДНОГО полинома; интеграл сворачивается в один полином J(Q) одной
   переменной, Q = D/2 + n - j - 2. keystone_beta.json, 6720 точных проверок.
2. **Знак старшего коэффициента = (-1)^(j-1).** Нечётные ножи не могут иметь
   порога вовсе, чётные обязаны. keystone_margin_law.json, 324 проверки.
3. **ЛЕММА СПУСКА (главное за смену).** Положительность всех волн при D+2
   влечёт положительность при D, РАВНОМЕРНО ПО СПИНУ. Механизм: связь
   Гегенбауэра при mu=a+1 обрывается на двух членах, c0>0 и c1<0, обратное
   соотношение -- положительная комбинация, индукция вниз по спину.
   keystone_dimension_walk.json: 120+120 точных проверок, 0 нарушений знака.

### Что это даёт

Всё НИЖЕ полосы D в (T_hat-2, T_hat] -- бесплатно, сразу для всех ножей.
Теорема свелась к полосе ШИРИНОЙ 2. На полосе сертификат МАНИФЕСТЕН: 1248
клеток сетки на глубине бисекции 0, включая j=2, который на всём отрезке не
сертифицировался вообще (там касание требует арифметики с корнем из 3).

### Идёт сейчас

lab/keystone_strip_symbolic.py -- сертификат на полосе, символьный по lam И
по n одновременно (одна клетка = целая ветвь берега x все уровни одной
чётности). Закрыто до j=10, 688 клеток, 0 провалов, прогон продолжается.

### Осталось

1. Довести сертификат на полосе по всем ветвям и j.
2. Последняя бесконечность -- j (варианты в плане: структура коэффициентов
   на полосе; индукция через Q_{j+1}=Q_j/(j-t); операторная лестница по n).
3. lam выше последней ветви (lam > ~26): вне покрытия, нужен хвостовой
   аргумент. По закону зазора там относительный запас тоньше всего (~1/lam).

### Измеренные закономерности (НЕ теоремы)

* Закон зазора: D* - берег -> C(j-2), C = 2.398 +- 0.002 (догадка 12/5 не
  заявляется). Берег растёт как (12+4sqrt3)lam.
* Самый опасный уровень n* = k(lam)-1: тесный нож едет по той траектории,
  что задаёт берег. Узкая клетка проекта: j=4, lam=26, n=44, спин 80, 1%.
* Low spin dominance (гипотеза Wang, arXiv:2403.00906) в CHR НЕ работает:
  минимизаторы при спинах 8..90, ни разу при l<=2.

### Связь с классикой (360-анализ)

Задача = вопрос Шёнберга (1942) о положительной определённости на сфере
S^(D-2): парциальные волны -- это коэффициенты Шёнберга, класс PD-функций
сужается с ростом размерности, поэтому берег ОБЯЗАН существовать -- это
геометрия сферы, а не физика струн. research/schoenberg-direction.md.
