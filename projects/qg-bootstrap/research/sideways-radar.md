# Sideways radar (founder 2026-08-14: «смотреть по сторонам очень жёстко»)

Правило: обновлять на КАЖДОЙ итерации; каждый наш результат прогонять через
вопрос «в какие ещё области это стреляет?». Ранжировано по (удар × близость).

## Куда стреляет наш станок уже сейчас

1. **Coon/гипергеометрические амплитуды** (живое сообщество: Hirst-related,
   2403.00906, Mansfield-Spradlin). Наш q-хронометр n_crit ~ 1.1/sqrt(q-1) —
   готовый вклад в их дебаты о позитивности q-деформаций; их работы в основном
   про 0<q<1, наш точный клинок — про q>1. ДЕЙСТВИЕ: короткая заметка/секция
   или письмо после гравитационной статьи.
2. **EFT-позитивность / бутстрап констант связи** (Caron-Huot et al.):
   крайние точки λ→0 и λ→∞ нашего гравитационного семейства = их «kinks».
   Наша карта λ_min(D) даёт этим углам динамику по глубине. Высокая близость.
3. **Hidden zeros / surfaceology** (Arkani-Hamed & co, 2607.27300):
   их «скрытые нули» против наших «двойных нулей» — возможно, один механизм.
   ДЕЙСТВИЕ: прочитать 2607.27300 полностью (уже в плане) и искать мост.
4. **AdS/CFT Виразоро-Шапиро** (2606.19283 дисперсионный бутстрап):
   наши замкнутые формы могут дать входы их alpha'-разложению.
5. **Метод как продукт**: «exact-arithmetic adversarial pipeline» (двухмаршевый
   оценщик + бритвы + атак-скрипты + validator-с-нуля) — методологическая
   статья/tooling для всего amplitude-сообщества (+ AI-in-science кейс:
   человеко-ИИ лаборатория с полным раскрытием). Роган-трек питается отсюда.
6. **Дальний прицел**: любые области с «численно отсканированными границами
   позитивности» — моментные задачи, устойчивость в теории управления,
   спектральная теория графов. Держать в фоне, не распыляться.
