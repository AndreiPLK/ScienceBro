## Корзина 2. Graft (nanonets)

[NanoNets/Graft](https://github.com/NanoNets/Graft) — 2,9k★, 6 недель от роду,
MIT, активен. «Контекстный слой» для больших кодовых баз: карта репозитория
в markdown, синхронизация через git, tree-sitter, MCP. Их цифры ускорения —
самозамеры, независимых нет. ScienceBro: НЕ НУЖЕН (наш CLAUDE.md+скиллы+память
делают это лучше вручную, репо маленькое). ИГРОВЫЕ ПРОЕКТЫ: КАНДИДАТ — на UE
Firebird и больших Godot-репо попробовать при следующей игровой сессии,
с инспекцией перед запуском (гоняет код через LLM API).

## Корзина 3. Статья «Graph Engineering» (Anatoli Kopadze, X)

Не репозиторий, а концепт. Проверено главное: dynamic workflows в Claude Code —
реальность (инструмент встроен). Схема «алмаза» (fan-out → reduce → verify на
чистом контексте → synthesize) ВНЕДРЕНА этой ночью: адверсариальный флот-критик
на теоремы ножей 4-5. Правила «проверяющий не делит контекст с работником» и
«якоря-гейты» у лаборатории уже были (устав). Для любого проекта: широкая
независимая работа → воркфлоу; глубокая последовательная → обычный луп.
