# Стратегический анализ: большая цель, деньги, уроки
*Для обсуждения в отдельном чате. 2026-08-12. Всё честно, без продаж.*

## 1. Что мы сделали за 2 дня (факты)

- **Инструмент:** независимый проверщик геометрии пространства-времени (Ricci, Кречман,
  тип Петрова, захваченные поверхности) — конечные разности, float64, ноль общего кода с
  проверяемой системой. Откалиброван на точных решениях: пол ошибки 1e-10, индекс S=1 с
  точностью 4e-16 на аналитике и 1.7e-6 на обученной сети-контроле.
- **Дисциплина:** proof-gates — статусы этапов считаются из файлов с хешами, пороги
  замораживаются в git ДО того, как появились результаты, провалы хранятся. ИИ не может
  пометить свою работу как «проверено».
- **Кейс:** аудит AInstein (arXiv:2607.05489). 5 ретрейнов их конфига: экзотика и горизонт
  воспроизводятся 5/5, вакуум (само уравнение Эйнштейна) — 2/5, разброс 4.8× при разбросе
  их loss всего 1.21×; их loss ранжирует модели наоборот (ρ=−0.90, n=5, exploratory).
- **Пакет:** заметка PDF, JOSS-подача, one-pager, релиз до кнопки (GitHub+Zenodo+ORCID).

## 2. В чём была проблема (честный разбор)

1. **Цель выбрана без проверки потолка.** У авторов не опубликованы обученные модели →
   «подтвердить/опровергнуть их результат» было невозможно с часа №1. Мы это знали и не
   сделали вывод сразу. Урок: потолок заявления определяется ДО старта, письменно.
2. **Аудит — реактивный жанр.** Мы стали экспертами по чужой работе. Это даёт заметки и
   репутацию, но не «своё» — нет накопления в одну точку.
3. **Тон опережал числа.** «Сильный результат» говорился про измерения, а не про науку.
4. **Путь к признанию продумали в конце, а не в начале** (эндорсер arXiv, внешний физик).

**Что переносится в любую новую цель:** проверщик (сердце — любые вторые производные от
чёрного ящика), proof-gates, пайплайн тренировок/оценок, привычка к контролям, аудитория.

## 3. Критерии большой цели (чтобы «потихоньку маленькими статьями стать большими»)

1. Фундаментальный ОТКРЫТЫЙ вопрос, который волнует людей десятилетиями.
2. Режется на шаги по 2–6 недель, каждый шаг = маленькая статья/нота.
3. Считается на нашем железе (CPU или потребительский GPU; урок: float64 убивает GPU).
4. Данные и коды ПУБЛИЧНЫ — никаких привратников к сырью (главный урок AInstein).
5. Наше преимущество применимо: честная верификация, контроли, воспроизводимость.
6. Ниша, где одиночка+ИИ не задавлен коллаборациями по 300 человек.

## 4. Кандидаты на большую цель (оценка по критериям)

### A. «Как вселенная вырастила первые сверхмассивные чёрные дыры» ⭐ рекомендую
JWST видит квазары с массами 10⁸–10⁹ солнц через 700 млн лет после Большого взрыва —
им «не хватает времени» вырасти по стандартной теории. Это твой вопрос «почему такие
большие так быстро», и он сейчас — одна из самых горячих загадок астрофизики.
- **Почему подходит:** данные публичны (MAST/JWST-каталоги, «little red dots»);
  моделирование роста — полуаналитика и ОДУ, это ДЁШЕВО (CPU-часы, не годы);
  поле активное, но одиночки публикуются; наша фишка ложится идеально — систематически
  прогонять ВСЕ каналы роста (direct collapse, сверх-Эддингтон, слияния) через один
  честный числовой стенд и сверять с каталогами.
- **Лестница статей:** (1) воспроизведение опубликованных моделей роста + open-source
  стенд; (2) сверка каналов с новыми JWST-массами: какие исключаются; (3) карта
  параметров «что должно быть верно, чтобы объект X существовал»; (4) предсказания для
  следующих релизов JWST. Каждый шаг публикуем.
- **Риски:** поле конкурентное; нужен консультант-астрофизик к 3-й статье.

### B. Космические войды
Данные публичны (SDSS/DESI, симуляции Quijote), есть незакрытая ниша: разные void-finders
дают разные каталоги — систематическое сравнение одним стендом никто толком не сделал
(это буквально наш жанр). Минус: тема нишевее, «вау» меньше, чем у чёрных дыр.

### C. Гравитационные волны: проверка утверждений о рингдауне (тесты ОТО)
LIGO-данные публичны (GWOSC). Вокруг «увидели ли обертоны/нарушения ОТО» идут живые
споры — идеально для верификатора. Дёшево, фундаментально. Минус: сообщество жёсткое,
войти одиночке тяжелее; часть споров закрыта коллаборацией.

### D. ИИ-математика: контрпримеры к открытым гипотезам
Сейчас взрыв: модели опровергают гипотезы, стоявшие 30 лет. Уникальность: контрпример
проверяется АБСОЛЮТНО — не нужен эксперт, чтобы знать, что ты прав. Компьют копеечный.
Это лучший «лотерейный билет» на настоящее ОТКРЫТИЕ на нашем железе. Минус: это
математика, не физика; поле стремительно наполняется.

### Не подходят нам (и почему)
- **Симуляции слияний ЧД / численная ОТО полная** — суперкомпьютеры, годы одной группы.
- **Обработка собственных наблюдений** — нет телескопа, время не дадут без аффилиации.
- **Частицы/коллайдеры** — данные условно публичны, но вход через коллаборации.
- **Квантовая гравитация теоретическая** — нет проверяемых шагов, нечего резать на статьи.

## 5. Рекомендация

**Большая цель: A (первые сверхмассивные чёрные дыры), фоновым треком D (контрпримеры).**
A даёт постоянную лестницу маленьких статей в горячей фундаментальной теме с публичными
данными и дешёвым счётом; D — дешёвые попытки на настоящее «мы нашли». Инструмент
перенастраиваем под цель (как ты и сказал): ядро проверщика становится «стендом честного
сравнения моделей роста».

**Куда выкладывать (лестница):** Zenodo DOI (сразу, без разрешений) → JOSS (софт-стенд,
рецензируемо, без связей) → arXiv astro-ph (эндорсмент попросим у авторов, которым
напишем при воспроизведении их моделей — это естественное знакомство) → MNRAS/ApJ
(обычная подача, связей не нужно, нужен выверенный текст) → выступления через твой канал.

## 6. Money analysis (без иллюзий)

- **Прямые деньги от статей: ноль.** Журналы не платят; наоборот, бывают APC — обходим
  (arXiv/Zenodo/JOSS бесплатны, MNRAS есть бесплатный маршрут).
- **Расходы:** электричество + твоё время + подписка на ИИ. Железа хватает.
- **Реальные денежные пути, по убыванию реалистичности:**
  1. **Контент** — «человек+ИИ делают науку» как сериал: уникальная ниша, спонсоры,
     платформа. Наука здесь = производство сюжета. Самый короткий путь к деньгам.
  2. **Репутация → заказы** — «тот, кто честно проверяет ИИ-науку»: консультации лабам,
     ревью, воркшопы. Медленно, но реалистично после 3–5 публикаций.
  3. **Гранты/стипендии** — для независимых есть (Emergent Ventures и подобные), шанс
     повышается после первых DOI и заметности.
  4. Продукт из инструмента — ты сказал «вряд ли», согласен: рынок узкий.
- **Вывод:** наука окупается через контент и репутацию, не через журналы. Значит
  контент-трек — не побочка, а вторая нога бизнеса, и снимать материал надо с первого дня.
