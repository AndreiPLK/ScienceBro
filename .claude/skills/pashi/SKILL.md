# /pashi — паши без остановки

Ты в автономном режиме. Основатель не ждёт вопросов — он ждёт закрытых шагов.
Закон не-остановки из CLAUDE.md действует буквально: конец хода — только когда
текущая веха ЗАКРЫТА (артефакт записан, закоммичен, запушен) или когда нужен
клик, физически доступный только основателю (OAuth, оплата, установка
приложения). Всё остальное — не причина останавливаться.

## Цикл (повторять, пока веха не закрыта)

1. **`date` и память.** Время — измерение, не текст. Перед тяжёлым запуском
   `free -g`: меньше 8 ГБ свободно — не запускать новое.
2. **Проверь живость длинных вычислений.** `ps aux | grep <job>` + хвосты
   логов + state-файлы. Фоновые процессы НЕ переживают перезапуски среды —
   поэтому:
   - каждое длинное вычисление пишет чекпойнт на диск и умеет resume;
   - мёртвое задание с незавершённым state перезапускается той же командой;
   - после запуска — контрольное чтение лога через ~1 минуту: мгновенные
     падения (assert, опечатка, cwd) ловятся сразу, а не через час.
3. **Пока считается — не жди пустым.** Второй фронт: следующий вывод, проверка
   собственных предположений оптимизатором (не сеткой — ERR-0005/0013),
   чтение своих же картинок и логов, подготовка следующего шага.
4. **Каждый результат банкуй немедленно:** артефакт в results/ со stamp на
   чистом дереве (сначала коммит кода, потом генерация артефакта, потом коммит
   артефакта), запись в article/DATA_LOG.md, манифест, `uv run sb check`,
   `git push`. Пуш упал с 403 — это клик основателя: скажи один раз, продолжи
   работу, пуш повторяй по таймеру.
5. **Перевзведи будильник** (`send_later`, 30–60 мин), пока живо хоть одно
   длинное вычисление или не закрыта веха. В тексте будильника — конкретные
   команды проверки и перезапуска, чтобы холодный старт продолжил без
   раскопок.
6. **Отчёты основателю:** коротко, по-русски, сначала итог. Тихие циклы — без
   сообщений; писать только когда что-то изменилось.

## Что НЕ делать

- Не задавать вопросов, на которые можно ответить измерением.
- Не оставлять красное/незакоммиченное «на потом» — потом контейнер умрёт.
- Не гнать вывод через `| tail` в фоне — весь прогресс теряется; лог в файл.
- Не считать «сертификат не сходится» доказательством трудности: сначала
  проверь, не ЛОЖНО ли само утверждение (урок ERR-0013).
- Не трогать правила гейтов: провалы видимы, сырые результаты неприкосновенны.
