# Research iteration — обязательный цикл

Полный контур (из чартера, порядок обязателен):
литература полным текстом → точная дыра → замороженные предположения и
оценщик → НЕСКОЛЬКО (≥3) подходов → адверсариальный поиск контрпримеров →
символьная+численная проверка → независимая реализация → аналитическое
доказательство → Lean-верификация → проверка новизны → физическая
интерпретация → proof pack.

## Железные правила итерации
1. НЕ влюбляться в первый подход — минимум 3 существенно разных кандидата.
2. Заморозить критерии оценки ДО просмотра финальных результатов.
3. Контрпримеры ищутся ДО попытки доказательства.
4. Известные ответы, негативные контроли, случайные точки, границы,
   асимптотики, свипы точности — обязательны.
5. Независимый валидатор не делит логику с кандидатом (машинно: z3_judge).
6. Проваленные кандидаты сохраняются с сигнатурой провала и уроком.
7. Ошибки цепочки доказательства = немедленный даунгрейд статуса (ERR-жур).

## Статусы истины (одна на утверждение)
IDEA → NUMERICALLY_SUPPORTED → ANALYTICALLY_PROVED → FORMALLY_VERIFIED →
PHYSICALLY_REVIEWED. Новизна отдельно: NOVELTY_UNCHECKED / PRIOR_ART_FOUND /
POTENTIALLY_NOVEL / EXPERT_NOVELTY_REVIEWED. Соответствие нашим claim-гейтам:
speculative≈IDEA, experimentally-supported≈NUMERICALLY_SUPPORTED,
independently-validated≈ANALYTICALLY_PROVED+чужой движок. Lean проверяет
формулировку, НЕ новизну и НЕ физический смысл.

## Каждая итерация заканчивается АРТЕФАКТОМ
Заметка с точными цитатами / исполняемый эксперимент / замороженный
протокол / контрпример / численный сертификат / аналитический вывод /
Lean-теорема / задокументированный отрицательный результат. НЕ роадмапом.

## Формат отчёта итерации (обязателен)
```
СЕЙЧАС ДОКАЗАНО:
ПОКА ТОЛЬКО ГИПОТЕЗА:
ЧТО ОПРОВЕРГНУТО:
НОВИЗНА:
АРТЕФАКТЫ И КОМАНДЫ:
ЗАЧЕМ ЭТО NORTH STAR:
СЛЕДУЮЩИЙ КОРОТКИЙ ЭКСПЕРИМЕНТ:
БЛОКЕРЫ:
```

## Честные оценки времени
Никаких «дней/недель» на глаз: сначала минимальный бенчмарк, замер
пропускной способности, экстраполяция; нет бенчмарка → estimate_confidence:
LOW и НАЧАТЬ немедленно. Задача, исполнимая сейчас, исполняется сейчас.
